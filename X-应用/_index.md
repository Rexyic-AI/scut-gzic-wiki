# 应用与工具

> 第四棵树，也是第三条索引轴：**用什么**。`A/`…`G/` 答“在哪”，`Z-主题/` 答“办什么”，`Y-组织/` 答“找谁”，这里答“点哪儿”。

## 为什么应用不能挂在主题下面

一个应用几乎从不只服务一个主题。“智慧服务”同时管班车（通行）、功能房（办事）、部分业务办理；把它放进“办事与服务”，找班车的人就永远碰不到它。

这正是分树三条测试里的第③条：**一个实体只出现一次**。当实体天然属于多个父节点，树会逼你选一个，选错就永久丢掉另一个视角。这时应当让它独立成树，再从各主题反向指回来——主题页的 `## 相关应用` 就是那些回指的指针。

## 写应用页的五段

每页固定五段，不增不减：

1. **一句话定位**——它在哪、主要解决什么。
2. **能办什么 / 不能办什么**——很多事两个入口都点得进去，只写真正生效的那个。
3. **操作步骤**——编号列出，细到“点哪个按钮”。
4. **踩坑**——身份不对导致功能缺失、要提前多久、失败后怎么办。
5. **待核实**——版本更新后可能失效的步骤。

> 第五段不是客套。小程序改版频繁，任何一条步骤都可能在某次更新后失效；写清“截至哪一次改版”，比写得详细更重要。

## 待核实
