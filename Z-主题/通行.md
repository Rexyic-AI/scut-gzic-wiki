# 通行

> 校区的通行逻辑只有一句话：一条河分南北，一条轴串南北，七座桥连两岸，二层连廊连楼群。

## 一览

| 场景 | 怎么走 |
|---|---|
| 出校门 | 六个校门：北大门、南大门、西北门、西南门、东北门、东南门（据官方导览图） |
| 坐公交 | A1 公交站在西南门内侧，是校外公交的落客点 |
| 坐地铁 | 番 87 在校内绕行，接 4 号线新造站，并连大学城校区；番 72 经北大门接 7 号线板桥站。用「广州交通行讯通」查实时到站 [S03] |
| 跨校区班车 | 在「GZIC智慧服务」→ 交通车预约，**凭码乘车、非预约不可乘**；连续 3 张或 30 日内 10 次失约，记黑名单 14 天。F2 南侧发车，经停 D2、B2 [S30] |
| 赶末班车 | 末站有余座时，学生可凭学生证搭教职工班车 [S30] |
| 南北过河 | 七座风格各异的人行景观桥（逐桥编号待补） |
| 雨天／暴晒 | 楼群二层连廊贯通；地下车库之间也有通道 |
| 开车 | 各楼栋设地下车库且地下连通；南门、北门设门卫 |
| 同级之间怎么走 | 看 `00-元数据/topology.csv` 边表：逐层转录疏散图后填入，可查“哪扇门通哪条廊、哪架梯到哪层” |
| 校内定位 | 抬头看楼顶街区编号：A–G 自西向东，1–6 自南向北 |

## 怎么选

第一次来先记住“河”这条线：碧河东西横穿，南岸教学科研、北岸生活休闲。迷路时先判断自己在河的哪一侧，再找最近的桥，比看地图快。
