# SCUT 国际校区百科全书

华南理工大学广州国际校区（A–G × 1–6 共 42 个格位，实有 29 个街区）的空间与办事知识库。纯 Markdown 文件树，**路径即语义**：`列/街区/子楼/楼层`。

> 学生自发整理，**非学校官方发布**。每一条事实都标注来源编号，能点回原始出处；查不到出处的宁可不写。
>
> 最后更新：2026-11-22

**当前规模**：**实有 29 个街区**——13 个已确认、16 个部分确认，其余 13 个编号在校区编码里并不存在（标 `✕`——**不是空地，是编码里没有这一格**）。能直接回答问题的页面约 50 篇，其余是待补的占位页与接口页。占位页标 `status: unknown`，意思是“这里我们不知道”，不是“这里没有”——请勿把占位当事实引用。

## 这是什么

一个可以按文件夹逐层深入、也可以被 AI 整库读取的校园志。回答三类问题：

| 你想知道 | 去哪 |
|---|---|
| 这个地方在哪、这栋楼里有什么 | `A/` … `G/`（按街区编码） |
| 这件事怎么办、几处怎么选 | `Z-主题/`（住宿、餐饮、自习、办事、通行……） |
| 这个功能用哪个小程序、点哪儿 | `X-应用/` |
| 这件事归谁管 | `Y-组织/` |

**四棵树各答一个问题，互不嵌套**：在哪、办什么、用什么、找谁。同一件事只在其中一处写正文，其余三处放指针——这样 200 多个文件不会分裂成四份副本。

## 不是什么

- **不是**官方地图。官方地图与三维校园在 [map.scut.edu.cn](https://map.scut.edu.cn)，本库只记“哪栋楼在哪个街区”。
- **不是**逃生指南。本库转录楼层的走廊、楼梯、出口关系（拓扑），但**不含疏散图原件**，紧急情况请以现场标识与学校指引为准。
- **不是**评价平台。只写可核验事实，不写对院系、课程、教师、后勤的评价。
- **不收录**：他人姓名与联系方式、门禁密码、监控点位、未公开规划、菜品价格、宿舍内部照片。这些不进公开库，不是遗漏。

## 怎么读

1. 先看 [`INDEX.md`](INDEX.md)：一张 42 格位的矩阵表（上北下南、A–G 自西向东 × 1–6 自南向北），`✕` 表示该编号不存在（不是空地）；加全库目录与体例。
2. 编码规则与歧义（街区号 / 楼栋号 / 房间号三种写法）看 [`00-元数据/编码对照表.md`](00-元数据/编码对照表.md)。
3. 按场景查 [`00-元数据/FAQ-常用问题索引.md`](00-元数据/FAQ-常用问题索引.md)。
4. **不确定的不要当事实用**：[`00-元数据/待核实清单.md`](00-元数据/待核实清单.md) 列了全部缺口，第四节是两个来源互相矛盾的条目。

### 不懂 Git 也能用

- **手机上**：点开链接就能读，不用装任何东西。仓库首页是文件树，点文件夹进去；页面顶部有目录可跳转。
- **想整库下载**：首页右上 `Code` → `Download ZIP`，解压就是普通文件夹，用任何编辑器或 Obsidian 打开都能读。
- **只想知道某件事**：先用仓库内搜索（页面右上放大镜），或直接问 AI「读这个仓库里关于宿舍／食堂／班车的部分」。
- **不想翻文件树**：先看 [`INDEX.md`](INDEX.md) 的街区矩阵，或 [`00-元数据/FAQ-常用问题索引.md`](00-元数据/FAQ-常用问题索引.md) 按场景查。

### 给 AI / 爬虫

根目录的 [`llms.txt`](llms.txt) 是全库每个 Markdown 文件的路径与标题清单，按树分组。读它一个文件即可知道有什么、在哪儿，再按需取具体页。`raw.githubusercontent.com/<owner>/<repo>/main/<路径>` 可直接取单文件（中文路径需百分号编码）。

`00-元数据/` 下的 CSV 是 **UTF-8 with BOM**（Excel 双击不乱码）；用脚本读取请指定 `utf-8-sig`，否则首个字段名会带一个不可见字符。

## 状态标记

每个文件头部有 frontmatter：

| 字段 | 取值 | 含义 |
|---|---|---|
| `status` | `confirmed` | 有公开来源可核验 |
| | `partial` | 有部分信息，仍有缺口 |
| | `unknown` | 只有占位，内容待补 |
| | `planned` | 接口壳：结构已定、正文未进，**不要当事实回答** |
| `updated` | 日期 | 最后核实日期，隔了很久的要重新核对 |
| `sources` | `[Sxx]` | 回指 `00-元数据/sources.md` |

## 数据来源

- 学校与各单位官网、官方公众号（每条 `[Sxx]` 可回溯到 `sources.md` 的完整标题、链接与访问日期）。
- 官方导览图：只转录街区编号与楼名，**不转载图片**。
- 公开报道与院系公告。
- 实地观察：只写事实（“这层有三处楼梯”），不写评价；照片原件不入库。

## 维护与更新

- **谁维护**：一名在校学生，业余整理，**不是学校部门**，也没有得到任何官方授权或背书。
- **更新节奏**：不固定。**学期初**（报到、选课、开课）和**学期末**（考试、假期安排）是集中修订期，其余时间按纠错零散更新。
- **看时效**：每个文件头部有 `updated:` 日期。超过一学期的内容请当参考、别当准信——班车时刻、开馆时间、施工围挡这几类变得最快。
- **报错**：提 issue 最快，写清「哪一页、哪句话、正确是什么、出处」四样。不方便用 GitHub 的，托认识的人转达也行。
- **不接受**：没有来源的修改、对院系或个人的评价、任何人的联系方式与照片。

## 贡献

- **纠错**：提 issue，附上可核验的来源链接。没有来源的修改不会被合并。
- **补内容**：照 `90-模板/` 里的模板写，`status` 从 `unknown` 起，核实后往上升。
- **两个来源矛盾**：不要折中，两个都留，写进街区页的「已知冲突」并登记 `待核实清单.md` 第四节。
- **不要提交**：他人信息、疏散图原件、门禁与监控细节、菜品价格、任何带人脸的照片。
