# 发布规范（公开 / 受控两级）

> 公开库发布到 GitHub；受控内容放在**库外**的兄弟目录 `../SCUT国际校区受控资料/`，永不进仓库。
> 本文件定死边界与派生方向。规则改动请改这里，不要靠在 `.gitignore` 里临时加行。

## 一、为什么是“库外”，而不是 `.gitignore`

`.gitignore` 只对**未跟踪**文件生效。已经提交过的文件，即使后来加进 `.gitignore`，仍留在历史里，`git log` 能取回，fork 与缓存收不回来。
把受控资料放在**仓库根目录之外**，git 根本看不到它——不依赖任何人记得加规则，也不怕哪天手滑 `git add .`。

> **硬约束：`git init` 必须在 `SCUT国际校区百科全全书/` 里执行，不能在上一级执行。** 在上一级 init 会把两个目录一起提交。

## 二、三级分类

| 级别 | 判定 | 处置 |
|---|---|---|
| **公开** | 能从学校官网、公众号、导览图、新闻稿等公开渠道取得；只描述设施、流程、位置 | 正常入库 |
| **受控** | 不可从公开渠道取得的；个人实地采集的；涉及安保、门禁、监控的；价格与商业明细；内部通知与截图 | 放受控库同路径，不进仓库 |
| **不记录** | 他人个人信息与联系方式；门禁密码、监控点位、安保布防；未公开的规划与施工；对具体个人或部门的评价 | 连受控库也不写 |

第三条不是在“藏”，是在“不写”。受控库将来也要给熟人看，它受访问控制，不是可以随便放的地方。

## 三、路径与派生

- 受控库与公开库**同路径镜像**：公开的 `D/D5区-一站式学生社区/L02.md`，对应受控库 `可分享 或 仅自己/D/D5区-一站式学生社区/L02/`。
- **单向派生**：原件（照片、价格表、通知截图）只进受控库；公开库放从它派生的**摘要文字**。不是两处各写一遍再同步，而是原件 → 摘要一个方向。
- **双向指针**：公开页写一句“原件见受控库同路径”，**不写 md 链接**（在 GitHub 上必定 404）；受控页写“已派生至公开库 `L02.md` 的「平面拓扑」节”。两边都找得到对方，将来不会忘了它存在。
- 受控库内部再分 `可分享/` 与 `仅自己/`，**新素材一律先进 `仅自己/`**，确认无识别信息后再上移到 `可分享/`。默认拒绝，不默认放行。

## 四、具体判定

| 内容 | 级别 | 理由 |

| 街区编码、栋名、楼层功能、房间号 | 公开 | 公开资料与门牌可见 |

## 五、上库前七项自检

1. **`git init` 的位置对**：在 `SCUT国际校区百科全全书/` 内，不在工作区根目录。
2. `git status` —— 只应出现预期文件；**出现受控库任何路径，说明 init 位置错了，删除 `.git` 重来**。
3. 全库搜敏感词：`疏散`、`密码`、`门禁`、`监控`、`价格`、`元/份`、手机号格式。
4. 图片：公开的图若有 EXIF 定位，先抹除；实地照片一律不进库。
5. 空目录：Git 不跟踪空目录，占位必须有文件（本库的 `status: unknown` 占位文件正好满足）。
6. 根目录三件套已就位：`README.md`（含免责句）、`LICENSE`（CC BY-NC-SA 4.0）、`.gitignore`（其中 `_local/` 是历史约定的兜底，保留无妨）。
7. 搜一遍 `公众号` 相关新增段落，确认没有把「仅见学生社团号、未见官方发布」的内容当成既定事实写进去。

## 六、README 里必须写的一句

> 本项目由学生自发整理，非学校官方发布。信息可能过期，涉及报名、缴费、门禁等以学校官方通知为准。

理由不只是免责：本库每条事实都带 `[Sxx]` 来源编号与 `updated` 日期，**“可核验”本身就是它相对网络帖子的优势**，声明与体例是一套东西。

## 七、许可

**待定，见 `00-元数据/待确认.md` Q01。** 建议 `CC BY-NC-SA 4.0`，四个部分各管一件事：

| 部分 | 含义 | 对学生使用的实际影响 |
|---|---|---|
| `BY` 署名 | 转载、摘编、做衍生都要注明来源 | 别人搬走时必须留仓库链接，你的名字不被抹掉 |
| `NC` 非商业 | 不得用于售卖、付费资料包、商业培训 | 不能拿去做成 9.9 元的“新生手册”卖 |
| `SA` 相同方式共享 | 改过之后必须用同一协议开放 | 别人不能把改过的版本改成“版权所有”锁起来 |
| `4.0` | 协议版本号（2013 年国际版） | 与你无关，写全称时带上即可 |

不选它的两个常见替代：`CC0` 完全放弃权利（别人可商用，与“供学生使用”的初衷不符）、`CC BY 4.0` 允许商用。
不使用校徽与学校视觉标识，避免被误认为官方产物；README 首屏写明“学生自发整理，非官方发布”。

## 八、受控库怎么分享

- 只打包 `可分享/` 一层，文件名带日期：`受控资料_可分享_20261121.zip`，压缩包设密码，密码另发。
- 每次分享后在 `90-清单/分享记录.md` 记一行：给谁、哪天、哪个版本。熟人之间的转发拦不住，至少要能追到源头。
- 分享包里的内容仍按本文件的“不记录”一条执行——让别人看到，不等于可以写进去。
