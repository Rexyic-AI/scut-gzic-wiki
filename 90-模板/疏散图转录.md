# 模板 · 疏散图转录

> 消防疏散图是校区里最被低估的一份免费图纸：每层楼道口都贴一张，画的正是这一层的完整拓扑。但它有三个硬限制，先认清再用。

## 一、它能给你什么

| 能读到 | 读不到 |
|---|---|
| 走廊形式（单廊 / 双廊 / 环廊 / 中庭回廊） | 房间编号 |
| 楼梯位置与数量（含封闭楼梯间） | 房间名称与功能 |
| 电梯数量与类型（客梯 / 货梯 / 消防梯） | 尺寸与面积（示意图不按比例） |
| 本层直通室外的安全出口 | 门是否上锁、是否常闭 |
| 与相邻楼栋的连廊接口 | 哪个是主入口、哪个是后勤门 |
| 房间轮廓个数与相对位置 | 无障碍坡度、门槛高差 |

结论：**它给拓扑，不给编号**。所以它回答不了“这层有哪些房间”，但能回答“这层怎么走通、有几个出口、几架梯”——而后者正是现有资料完全空白的一块，也是“门禁、疏散、无障碍”三件事共同的地基。

## 二、转录成什么（六项固定字段）

写进该层 `L0x.md` 的 `## 平面拓扑` 节：

| 字段 | 写法 | 例（示意，非实测） |
|---|---|---|
| 走廊形式 | 单廊 / 双廊 / 环廊 / 中庭回廊 | 环廊，绕中庭一周 |
| 竖向交通 | 楼梯 N 处 + 方位；电梯 N 部 + 类型 | 楼梯 2（东南角、西北角）；客梯 2（中部） |
| 安全出口 | 本层直通室外的门 N 处 + 方位 | 2 处（南端、北端） |
| 房间轮廓 | 沿走廊的开口数 N 个（按图数，卫生间单列） | 约 14 个 |
| 邻接 | 与哪栋 / 哪层连通 | 东端连廊通 D5d；无错层 |
| 疑点 | 图上与实地不符、看不清的 | 西端标注“设备间”，待查 |

六项里最值钱的是第 5 项。房间数量可以数，邻接关系数不出来——它决定了“雨天能不能不出楼走到隔壁栋”。

## 三、还要写一份边表

疏散图真正稀缺的东西是**边**：哪扇门通哪条廊、哪架梯到哪层、哪条连廊接哪栋。这是“关系”，文件夹表达不了，写成 `00-元数据/topology.csv`：

| from | to | type | layer | note |
|---|---|---|---|---|
| D5f-L2 | D5d-L2 | 连廊 | 跨楼 | 二层连廊，双层结构 |
| F3-L2 | F3-L3 | 楼梯 | 跨层 | 东南角封闭楼梯间 |

端点写法与楼层页 `id` 一致（`子楼-L层`）；街区级关系直接写街区码（`D5`）。有了边表，才能回答“从 D5f 到 D5d 怎么走”“雨天能不能不淋雨走到 E3”。

## 四、分发边界（重要）

疏散图属安保信息。**原图不要进压缩包**：

- 原图存本地私有目录（如 `90-模板/assets/私有/`，或干脆放工作区外），仅供自己查阅；
- 库里只放**转录后的文字**——六项字段 + 边表。文字化之后信息量保留八成，敏感度降一个量级；
- 确实要放图，先做去标注：抹掉疏散方向箭头、集合点、消防设施位置，只留墙线与门洞。

## 五、操作顺序

1. 一层拍一张，正对、无遮挡，务必带上图签（楼栋与楼层号写在图签里，不拍图签等于拍了一张无主的图）。
2. **当天转录**，不要攒。攒到十张就分不清哪张是哪层。
3. 房间号另起一轮：沿走廊拍门牌，补进 `## 平面与房间表`。两轮不要混——混了就变成“边看图边猜”，而猜出来的房间号比空着更糟。

## 六、先做哪几处

F3（101 间课室，编号段全空）与 D5 各栋（房间号已有一半）价值最高。D6 次之（场馆分层完全空白）。G5 教师公寓不必做——住户信息无公开价值。
