# 人机协作协议

> 这页不是给读者看的，是给"下一次合作"看的。人和 AI 都按它办事。
> 改一条规则，同步在 [决策记录](决策记录.md) 记一行——否则下次重跑或换会话，规则就回退了。

## 一、回报格式：固定五段

每轮回复按这个顺序，不增不减：

1. **先说明**——直接回答你这次问的每一问，包括异议和"做不到"。**没问的不写**，不要在这里复述工作内容。
2. **改了什么**——动了哪些文件、改成什么。可自查、可回退。
3. **新增什么**——新文件、新约定、新数据。
4. **需要你知道**——**只有这一段必读**：风险、冲突、我替你做的假设、可能踩的坑。
5. **下一步**——谁做什么，卡在哪。

替换掉原来的"先总结、再请示"：以前是先汇报再问，一轮一问；现在是先回答、再交付、只在必要时开口。

## 二、五条默认

| 规则 | 具体做法 |
|---|---|
| ① 默认执行、事后否决 | 只要可逆，我说明"按 X 处理，除非你反对"，然后直接做，不占你一轮确认 |
| ② 只问不可逆的 | 见第三节清单；其余自己定，在「需要你知道」里标 `假设：` |
| ③ 决策进记录 | 定下的事写进 `决策记录.md`，**同一件事不回头问第二遍** |
| ④ 假设显式化 | 凡是没经你确认就采用的判断，正文与会话里都写"假设："字样，便于日后推翻 |
| ⑤ 你下指令用肯定句 | "我决定 X，除非你反对"比"你觉得 X 行吗"省一整轮；我只在有异议时开口 |

## 三、什么算不可逆（必须问）

- 删除、覆盖、重命名已有内容或目录
- 对外发布：上 GitHub、改许可、公开链接
- 涉及第三方：他人姓名、联系方式、对具体人或部门的评价
- 改库名、改目录结构、改体例约定（这三样会连锁影响几百个文件）
- 花钱、装软件、让你去跑腿以外的事
- 代表你去联系任何人

其余都归"可逆"：措辞、表格列序、单文件补一句、来源补登、新建占位文件、重跑脚本。这些我直接做。

## 四、什么时候值得并行

| 值得开子代理 | 不值得 |
|---|---|
| 批量只读检索：10 个应用的用法、10 篇公众号抓取、部门清单核对、多个来源交叉验证 | 改同一个文件或同一个脚本——必然冲突，合并成本高于自己写 |
| 彼此独立、只要结论、不要过程 | 需要体例判断的写作——子代理不知道这 12 条约定，产出要返工 |

**不推荐开新窗口做本项目的写作任务。** 这个库靠 12 条体例、分级规则、脚本约定运转，新窗口要重新喂一遍上下文，成本大于收益，且产出风格会漂移。新窗口适合"和本项目无关的一问一答"。

判断一句话：**读得多、写得少 → 并行；写得深、判断多 → 单线。**

## 五、你这边最省力的三个动作

1. **成组给，不要一张一张给**：一次一组照片（一层一组、一栋一组），比一次一张快一个数量级。
2. **按规范命名**：`L02-疏散图-20261121.jpg`（楼层-内容-日期）。名字带信息，我就不用逐张问"这是哪层"。
3. **给链接，不用给正文**：公众号文章把链接发来即可，正文与图片都能读（见第六节）。

## 六、工具边界（当前实测）

| 能读 | 读不到 |
|---|---|
| 公众号正文、发布日期、公众号名 | 需登录、需验证、已删除的文章 |
| 公众号里的图片（含全图型文章的配图、楼层图、价目表截图），长图会分段识读 | 视频、音频、小程序内部页面、H5 交互页 |
| 静态平面图（可读出街区编号、楼名、图例） | 三维校园、瓦片地图（`map.scut.edu.cn` 那类） |
| docx / xlsx / pdf / 图片 | 需要点击才加载的折叠内容 |

公众号取图的办法已固化为本地脚本 `_wx_read.py`（`python _wx_read.py <文章链接>`，在库外的工作区根目录，不进公开仓库）：抓正文与图片地址，图片下载后逐张识读。**不需要额外插件。**

## 七、改动流程：一处逻辑，三处同步

改结构或规则时，三处同时改，缺一处下次重跑就回退：

1. `_build_scut.py`——生成逻辑（真正的执行层）
2. `INDEX.md` 或本页——规则文本（给人看）
3. `决策记录.md`——为什么这么定（给未来看）

手写的文件（本页、决策记录、待确认）**不受脚本覆盖**：脚本只写它自己生成的文件，重跑不会冲掉这三份。

## 八、本协议的维护

- 觉得哪条不好用，直接说"改第 N 条"，我改文本并记一行决策。
- 不要往这里加"注意事项"式的零碎内容——规则超过 15 条就没人看。细节放对应文件自己的说明里。
- 三份文件（本页、`决策记录.md`、`待确认.md`）在 Windows 桌面有快捷方式，双击用 VS Code 直接打开。
