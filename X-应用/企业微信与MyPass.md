# 企业微信与 MyPass

> 学校的**身份底座**：通知、审批、报到都在企业微信里，MyPass 是其中的报到模块。没绑定它，很多事连入口都看不到。

覆盖主题：[办事与服务](../Z-主题/办事与服务.md) · [通行](../Z-主题/通行.md)

## 一句话定位

先绑企业微信，再做别的。报到注册、接收通知、走过审批，全都挂在这一个身份上。

## 能办什么

| 功能 | 入口 | 备注 |
|---|---|---|
| 开学报到 | 通讯录 → 我的企业 → 华南理工大学 → My Pass；或 enroll.scut.edu.cn | **手机定位在校内 + 人脸识别通过**，两个条件同时满足才算报到成功 [S17] |
| 接收通知 | 企业微信消息 | 院系、书院的正式通知多从这里下发 |
| 接送站预约 | MyPass 内预约 | 报到期间广州站、广州东站、广州南站有免费接站大巴，需提前预约 |
| 审批与请假 | 待核实 | 各院系流程不一 |

## 操作步骤（报到）

1. 先在迎新系统 `freshman.scut.edu.cn` 激活统一认证账号，绑定企业微信 [S18]。
2. 进「My Pass」→「开学报到」→ 开始报到。
3. 采集自拍人脸，裁剪调整后提交，约 10 秒出结果。
4. 显示「已报到」即成功；显示失败点感叹号看原因、重拍。

## 踩坑

- **只连校园 Wi-Fi 不算定位**：系统校验的是手机定位在校园范围内，两个条件缺一不可 [S17]。
- **未缴清学费住宿费只能报到、不能注册**：盖预注册章，未注册者不予选课、查不了成绩 [S17]。
- 人脸多次失败不要硬试，找辅导员线下协助，比反复重拍快。
- 换手机、换号后要重新绑定，否则收不到通知。

## 待核实

- 企业微信里可用的应用清单（报修、缴费是否也在其中）
- 各院系审批与请假的入口是否统一
- 毕业生离校后的账号回收规则
