# 智慧服务（微信小程序）

> 校区的万能入口之一：班车、功能房、报修、缴费、门锁、失物招领都从这里进。**功能按住宿区下发**，同一个小程序在不同人手机上长得不一样。

覆盖主题：[通行](../Z-主题/通行.md) · [办事与服务](../Z-主题/办事与服务.md) · [运动与场馆](../Z-主题/运动与场馆.md) · [住宿](../Z-主题/住宿.md)

## 一句话定位

校区生活事务的总入口：**九项功能**，从坐车到开宿舍门都在里面。先认证，再办事；**看到的功能比别人少，多半是住宿区或身份不同，不是小程序坏了**。

## 能办什么

| 功能 | 入口路径 | 说明 |
|---|---|---|
| 交通车预约 | 服务目录 → 交通车预约 → 立即预约 → 查询车票 → 去预约 | **必须先预约，凭码乘车**；上车给司机扫码核销 [S30][S46] |
| 功能房申请 | 申请目录 → 功能房申请 → 功能房预定 → 立即预定 | 自助厨房、排练厅、琴房等；**审核通过后到所在楼栋宿管处登记，押本人学生卡** [S47] |
| 场馆预约 | 服务目录 → 场馆预订 | 羽毛球、篮球、泳池等收费场；可提前两天 [S47] |
| 在线报修 | 申请目录 → 在线报修 → 报修申请 | 填单后维修师傅按约定时间上门；急事也可直接去 D5e 驿站 [S46][S47] |
| 生活缴费 | 生活缴费 → 绑定房间 → 选缴费类型 | **只覆盖 A4、F5 区**的冷水费与电费 [S47] |
| 门锁小助手 | 服务目录 → 门锁小助手 → 开锁 | **只覆盖 D5 区**，蓝牙开门，忘带钥匙时用 [S46][S47] |
| 线上键对键 | 服务目录 → 线上键对键 → 开始反馈 | 意见与建议，可上传图片，会得到回复 [S46][S47] |
| 失物招领 | 服务目录 → 失物招领 | 发布寻物／招领；实体兜底是 D5e 驿站 [S46][S47] |
| 校区资讯 | 服务目录 → 校区资讯 | 交通车时刻表、值班安排、学术预告与教研通知 [S46] |

> **首次使用必须先在「个人中心 → 账号认证 → 统一身份认证」登录**，否则只能看到部分功能——这一步卡住的人数最多 [S44]。课室借用不在小程序里，走学校网上办事大厅 [S46]。

## 操作步骤

### 交通车预约（三校区班车）

1. 进小程序，先在「个人中心」完成统一身份认证（只需一次）。
2. 常用入口 →「交通车预约」，选线路（五山／大学城）与班次。
3. 提交后生成乘车码，**上车出示**；没有码不能上。
4. 赶不上就及时取消——空占名额会计入失约。

规则：连续 3 张或 30 日内 10 次失约，记黑名单 14 天 [S30]。末站有余座时，学生可凭学生证搭教职工班车 [S30]。

### 功能房申请（不是“预约”）

1. 申请目录 →「功能房申请」→「功能房预定」→「立即预定」，选房间与时段。
2. 等审核通过（部分房间要书院或导师批）。
3. **带本人学生卡**到该楼栋宿管处登记，卡押在那里，用完取回 [S47]。

书院功能房免费；没做第 3 步等于没预约成功。

### 宿舍门锁（仅 D5 区）

服务目录 →「门锁小助手」→ 选钥匙包里的钥匙 → 开锁。手机需开蓝牙，人在门附近。A4、F5 不在此列——那边的门禁方式见 [住宿](../Z-主题/住宿.md)。

## 踩坑

- **不预约不能乘车**，现场补不了；周末与假期班次少，容易满。
- **失约是累计的**：连续 3 张或 30 日内 10 次没上车，直接停 14 天。
- **功能按身份和住宿区下发**：缴费只对 A4／F5，门锁只对 D5。看到“功能缺失”先确认这两件事，再查认证状态。
- 功能房预约成功后不去宿管登记，进不了门；登记要押学生卡，别把卡落在宿舍。
- 缴费结果不一定实时同步到财务系统，交完截图留存。

## 待核实

- 班车提前多久必须预约、发车前多久停止预约
- 取消是否计入失约、能否改签
- 功能房的可预约时段与审批流（哪些房间要导师或书院批）
- 缴费覆盖哪些项目（学费、住宿费、补考费？）
- A4、F5 的门禁与缴费是否有小程序之外的入口
