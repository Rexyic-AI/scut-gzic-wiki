# 景观与休闲

> 景观不是装饰，它是校区的组织骨架：一条南北主轴、一条东西水轴。

## 一览

| 节点 | 位置／说明 |
|---|---|
| 礼仪主轴 | 南门广场 → 礼仪广场（E2）→ E3 图书馆 → 碧河 → E5 双创中心，南北贯通 |
| 碧河（曲水流觞） | 东西横穿校区，串联跌级水道、亲水栈桥 |
| 兰亭 | 东岸，出挑河面 |
| 水岸剧场 | 西岸，与跌级水道相邻 |
| 龙舟码头与赛道 | 碧河，2 条 400 m 赛道 |
| 阳光草坪 | 中轴，密林草坪，大实大虚 |

## 怎么选

拍照按“主轴三段”走：E2 广场拍对称，E3 拍“博士帽”，碧河拍水面与桥。傍晚逆光时碧河最好看。
